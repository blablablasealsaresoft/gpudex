Getting Started

The GPUDex API provides programmatic access to GPU pricing data across 15+ providers. Get real-time prices, historical data, and ML-powered predictions.

API Key

Don't have an API key? Sign up for free

GET /api/v1/prices

Get current GPU prices from all providers

curl -H "Authorization: Bearer YOUR_API_KEY" \ "https://api.gpudex.ai/api/v1/prices?gpu_type=RTX 4090"
POST /api/v1/rentals

Create a new GPU rental

curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"gpu_type": "RTX 4090", "provider": "vast", "hours": 24}' \ "https://api.gpudex.ai/api/v1/rentals"
GET /api/v1/analytics/overview

Get market analytics and trends

curl -H "Authorization: Bearer YOUR_API_KEY" \ "https://api.gpudex.ai/api/v1/analytics/overview"
